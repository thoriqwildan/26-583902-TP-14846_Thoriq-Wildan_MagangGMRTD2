## Setup step-by-step

1. 'git clone https://github.com/thoriqwildan/26-583902-TP-14846_Thoriq-Wildan_MagangGMRTD2.git'
2. 'cd 26-583902-TP-14846_Thoriq-Wildan_MagangGMRTD2/python'
3. 'python3 -m venv env'
4. 'source env/bin/activate' itu command di linux, klo di windows kurtaw
5. 'pip install -r requirements.txt'
6. run main.py nya
7. harusnya sih itu aja
